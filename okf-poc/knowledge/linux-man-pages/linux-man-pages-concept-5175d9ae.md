## NAME         [top](https://man7.org/linux/man-pages/man8/accton.8.html#top_of_page)

```
       accton -  turns process accounting on or off
```

## SYNOPSIS         [top](https://man7.org/linux/man-pages/man8/accton.8.html#top_of_page)

```
       accton [OPTION] on|off|filename

       accton [ -V | --version ] [ -h | --help ]
```

## DESCRIPTION         [top](https://man7.org/linux/man-pages/man8/accton.8.html#top_of_page)

```
       accton filename turns on process accounting.
```

## RETURN VALUE         [top](https://man7.org/linux/man-pages/man3/a64l.3p.html#top_of_page)

```
       Upon successful completion, a64l() shall return the long value
       resulting from conversion of the input string. If a string pointed
       to by s is an empty string, a64l() shall return 0L.

       The l64a() function shall return a pointer to the radix-64
       representation. If value is 0L, l64a() shall return a pointer to
       an empty string.
```

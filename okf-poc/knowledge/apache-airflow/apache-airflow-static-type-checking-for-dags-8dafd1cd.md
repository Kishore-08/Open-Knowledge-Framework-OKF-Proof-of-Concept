### Static Type Checking for Dags

If you type-check your Dags with `mypy`, the optional
[apache-airflow-mypy](https://pypi.org/project/apache-airflow-mypy/) plugins give accurate results for
Airflow-specific patterns such as typed decorators and operator outputs. See
[Static Type Checking for Dags](https://airflow.apache.org/docs/apache-airflow/stable/howto/static-type-checking.html) for installation and configuration.

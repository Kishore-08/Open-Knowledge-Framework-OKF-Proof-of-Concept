# Installation of Airflow®

This page describes installation options that you might use when considering how to install Airflow®.
Airflow consists of many components, often distributed among many physical or virtual machines, therefore
installation of Airflow might be quite complex, depending on the options you choose.

You should also check out the [Prerequisites](https://airflow.apache.org/docs/apache-airflow/stable/installation/prerequisites.html) that must be fulfilled when installing Airflow
as well as [Supported versions](https://airflow.apache.org/docs/apache-airflow/stable/installation/supported-versions.html) to know what are the policies for the supporting
Airflow, Python and Kubernetes.

Airflow requires additional [Dependencies](https://airflow.apache.org/docs/apache-airflow/stable/installation/dependencies.html) to be installed - which can be done
via extras and providers.

When you install Airflow, you need to [setup the database](https://airflow.apache.org/docs/apache-airflow/stable/installation/setting-up-the-database.html) which must
also be kept updated when Airflow is upgraded.

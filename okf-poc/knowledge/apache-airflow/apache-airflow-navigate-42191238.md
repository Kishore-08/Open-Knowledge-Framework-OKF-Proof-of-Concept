# Integration

Airflow has a mechanism that allows you to expand its functionality and integrate with other systems.

- [API Authentication backends](https://airflow.apache.org/docs/apache-airflow/stable/security/api.html)
- [Email backends](https://airflow.apache.org/docs/apache-airflow/stable/howto/email-config.html)
- [Executor](https://airflow.apache.org/docs/apache-airflow/stable/core-concepts/executor/index.html)
- [Kerberos](https://airflow.apache.org/docs/apache-airflow/stable/security/kerberos.html)
- [Logging](https://airflow.apache.org/docs/apache-airflow/stable/administration-and-deployment/logging-monitoring/logging-tasks.html)
- [Metrics (statsd)](https://airflow.apache.org/docs/apache-airflow/stable/administration-and-deployment/logging-monitoring/metrics.html)
- [Operators and hooks](https://airflow.apache.org/docs/apache-airflow/stable/operators-and-hooks-ref.html)
- [Plugins](https://airflow.apache.org/docs/apache-airflow/stable/administration-and-deployment/plugins.html)
- [Listeners](https://airflow.apache.org/docs/apache-airflow/stable/administration-and-deployment/listeners.html)
- [Secrets backends](https://airflow.apache.org/docs/apache-airflow/stable/security/secrets/secrets-backend/index.html)
- [Web UI Authentication backends](https://airflow.apache.org/docs/apache-airflow/stable/security/api.html)
- [Serialization](https://airflow.apache.org/docs/apache-airflow/stable/authoring-and-scheduling/serializers.html)

It also has integration with [Sentry](https://airflow.apache.org/docs/apache-airflow/stable/administration-and-deployment/logging-monitoring/errors.html) service for error tracking. Other applications can also integrate using
the [REST API](https://airflow.apache.org/docs/apache-airflow/stable/stable-rest-api-ref.html).

## Using Public Interface to integrate with external services and applications

Tasks in Airflow can orchestrate external services via Hooks and Operators. The core functionality of
Airflow (such as authentication) can also be extended to leverage external services.
You can read more about providers [providers](https://airflow.apache.org/docs/apache-airflow-providers/index.html "(in apache-airflow-providers vstable)") and core
extensions they can provide in [providers](https://airflow.apache.org/docs/apache-airflow-providers/core-extensions/index.html "(in apache-airflow-providers vstable)").

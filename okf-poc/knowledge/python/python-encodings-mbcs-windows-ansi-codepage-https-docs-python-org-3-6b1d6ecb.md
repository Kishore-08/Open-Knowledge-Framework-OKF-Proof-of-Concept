## `encodings.mbcs` — Windows ANSI codepage[¶](https://docs.python.org/3/library/codecs.html#module-encodings.mbcs "Link to this heading")

This module implements the ANSI codepage (CP\_ACP).

[Availability](https://docs.python.org/3/library/intro.html#availability): Windows.

Changed in version 3.2: Before 3.2, the *errors* argument was ignored; `'replace'` was always used
to encode, and `'ignore'` to decode.

Changed in version 3.3: Support any error handler.

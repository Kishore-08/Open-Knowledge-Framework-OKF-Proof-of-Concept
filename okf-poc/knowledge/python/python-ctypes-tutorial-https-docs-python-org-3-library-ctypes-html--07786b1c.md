## ctypes tutorial[¶](https://docs.python.org/3/library/ctypes.html#ctypes-tutorial "Link to this heading")

Note: Some code samples reference the ctypes [`c_int`](https://docs.python.org/3/library/ctypes.html#ctypes.c_int "ctypes.c_int") type. On platforms
where `sizeof(long) == sizeof(int)` it is an alias to [`c_long`](https://docs.python.org/3/library/ctypes.html#ctypes.c_long "ctypes.c_long").
So, you should not be confused if `c_long` is printed if you would expect
`c_int` — they are actually the same type.

### Internal Objects[¶](https://docs.python.org/3/library/stdtypes.html#internal-objects "Link to this heading")

See [The standard type hierarchy](https://docs.python.org/3/reference/datamodel.html#types) for this information. It describes
[stack frame objects](https://docs.python.org/3/reference/datamodel.html#frame-objects),
[traceback objects](https://docs.python.org/3/reference/datamodel.html#traceback-objects), and slice objects.

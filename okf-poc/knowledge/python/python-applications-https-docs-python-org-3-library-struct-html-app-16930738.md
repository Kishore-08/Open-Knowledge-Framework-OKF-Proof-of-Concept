## Applications[¶](https://docs.python.org/3/library/struct.html#applications "Link to this heading")

Two main applications for the `struct` module exist, data
interchange between Python and C code within an application or another
application compiled using the same compiler ([native formats](https://docs.python.org/3/library/struct.html#struct-native-formats)), and
data interchange between applications using agreed upon data layout
([standard formats](https://docs.python.org/3/library/struct.html#struct-standard-formats)). Generally speaking, the format strings
constructed for these two domains are distinct.

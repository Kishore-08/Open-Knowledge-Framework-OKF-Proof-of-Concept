## Exceptions[¶](https://docs.python.org/3/library/pathlib.html#exceptions "Link to this heading")

*exception* pathlib.UnsupportedOperation[¶](https://docs.python.org/3/library/pathlib.html#pathlib.UnsupportedOperation "Link to this definition")
:   An exception inheriting [`NotImplementedError`](https://docs.python.org/3/library/exceptions.html#NotImplementedError "NotImplementedError") that is raised when an
    unsupported operation is called on a path object.

    Added in version 3.13.

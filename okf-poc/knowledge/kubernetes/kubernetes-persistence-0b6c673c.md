## Persistence

Kubernetes stores the serialized state of objects by writing them into
[etcd](https://kubernetes.io/docs/tasks/administer-cluster/configure-upgrade-etcd/ "Consistent and highly-available key value store used as backing store of Kubernetes for all cluster data.").

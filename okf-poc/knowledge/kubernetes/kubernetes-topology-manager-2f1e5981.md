## Topology manager

FEATURE STATE:
`Kubernetes v1.27 [stable]`(enabled by default)

*Topology Manager* is a kubelet component that aims to coordinate the set of
components that are responsible for these optimizations. To learn more, read
[Control Topology Management Policies on a Node](https://kubernetes.io/docs/tasks/administer-cluster/topology-manager/).

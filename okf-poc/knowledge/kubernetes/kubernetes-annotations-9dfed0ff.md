# Annotations

You can use Kubernetes annotations to attach arbitrary non-identifying metadata
to [objects](https://kubernetes.io/docs/concepts/overview/working-with-objects/#kubernetes-objects "An entity in the Kubernetes system, representing part of the state of your cluster.").
Clients such as tools and libraries can retrieve this metadata.

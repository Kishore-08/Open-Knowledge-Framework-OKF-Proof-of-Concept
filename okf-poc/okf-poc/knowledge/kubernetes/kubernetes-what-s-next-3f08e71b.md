## What's next

- Learn about the [PodGroup API](https://kubernetes.io/docs/concepts/workloads/podgroup-api/) overview and structure.
- Learn about the [Workload API](https://kubernetes.io/docs/concepts/workloads/workload-api/) that provides `PodGroupTemplates`.
- See how Pods reference their PodGroup via the [scheduling group](https://kubernetes.io/docs/concepts/workloads/pods/scheduling-group/) field.
- Understand the [gang scheduling](https://kubernetes.io/docs/concepts/scheduling-eviction/gang-scheduling/) algorithm.
- Read [PodGroup scheduling policies](https://kubernetes.io/docs/concepts/workloads/workload-api/policies/) for details on `basic` and `gang`.
